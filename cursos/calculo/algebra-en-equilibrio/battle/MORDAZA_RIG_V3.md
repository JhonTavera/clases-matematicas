# Mordaza Abisal — rig modular v3

Cada hoja usa una cuadrícula 2×2. Phaser recorta cada cuadro con las medidas indicadas.

| Recurso | Tamaño de cuadro | Estados, de izquierda a derecha y de arriba abajo |
| --- | --- | --- |
| `mordaza-rig-base-v3.webp` | 768×512 | agresivo, herido desafiante, súplica protegida, miedo sin coraza |
| `mordaza-rig-claw-v3.webp` | 627×627 | alzada, ataque, caída herida A, caída herida B |
| `mordaza-rig-legs-v3.webp` | 627×627 | apoyo A, apoyo B, colapso A, colapso B |
| `mordaza-rig-armor-v3.webp` | 627×627 | íntegra, golpeada, fractura, fragmentos en caída |
| `mordaza-rig-mouth-v3.webp` | 627×627 | reposo, carga, disparo, inutilizada |

Las tenazas, patas y boca permanecen visibles después de ser vencidas. La coraza es la única pieza que se desprende. El cuerpo cambia a súplica cuando quedan inutilizadas ambas tenazas y la boca; sin coraza, cambia a miedo intenso.
