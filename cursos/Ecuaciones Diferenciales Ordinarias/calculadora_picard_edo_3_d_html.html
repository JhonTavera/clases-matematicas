Calculadora de iteraciones de Picard

Para sistemas de ecuaciones diferenciales ordinarias de dimensión 3: \[\mathbf y'(t)=\mathbf f(t,\mathbf y(t)),\qquad \mathbf y(t_0)=\mathbf y_0.\]

Datos del sistema

\[ \mathbf y_{n+1}(t)=\mathbf y_0+\int_{t_0}^{t}\mathbf f(s,\mathbf y_n(s))\,ds \]
Las integrales se aproximan numéricamente con el método seleccionado. La iteración inicial se toma constante: \(\mathbf y_0(t)=\mathbf y(t_0)\).
